# ⚡ Quick Start

## 🚀 Comece em 30 segundos

### Passo 1: Copie o Script
```
👉 Vá para: auto-servehop.lua
👉 Copie TODO o código (Ctrl+A, Ctrl+C)
```

### Passo 2: Cole no Executor
```
1. Abra seu executor (Delta, Synapse, etc)
2. Cole o código na aba "Script"
3. Clique em "Execute"
```

### Passo 3: Pronto! ✅
```
O script vai começar a fazer servehop automaticamente
Veja os logs para acompanhar
```

---

## ⚙️ Configuração Rápida

Quer mudar o comportamento? Edite estas linhas no topo do script:

```lua
MIN_PLAYERS = 5    -- Muda para 10 se quer salas maiores
MAX_PLAYERS = 25   -- Muda para 50 se quer salas cheias
DELAY_HOP = 2      -- Muda para 1 se quer mais rápido
```

---

## 📊 Comandos/Status

O script mostra automaticamente:
- ✅ Quando conecta a um novo servidor
- ⚠️ Se não encontrar servidores
- 📈 Total de hops realizados

---

## ❌ Problemas?

**Script não faz nada?**
- Verifique se o executor está funcionando
- Tente aumentar `DELAY_HOP` para 5

**Muito lento?**
- Diminua `DELAY_HOP` para 1
- Aumente `MAX_PLAYERS` para 50

**Crashes?**
- O script tem proteção contra isso
- Se crashar, feche e abra o executor novamente
